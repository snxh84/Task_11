# Thala 7 — Sneaker Store (CSS Mini Project)

# About the project 

Thala 7 is a simple sneaker e-commerce website created using HTML and CSS. It provides a clean and user-friendly design for displaying sneakers, viewing product details, managing a shopping cart layout and viewing a checkout page.

# Pages included

•⁠  ⁠Homepage (index.html) – Introduces the sneaker store with the navigation bar, a hero section, a sneaker image, and a shop now button.
•⁠  ⁠⁠Product page (product.html) – display sneaker details, product images, price, quantity, selector and add to cart button. 
•⁠  ⁠⁠Shopping cart (cart.html) – shows the selected product layout, quantity, price, section and order summary.
•⁠  ⁠⁠Payment page (payment.html) – contains a checkout form with email, card details, country, ZIP Code and order summary.

# Features

•⁠  ⁠Simple and attractive user interface.
•⁠  ⁠⁠Easy navigation between four pages.
•⁠  ⁠⁠Flexbox layout for arranging page elements.
•⁠  ⁠⁠Responsive layout for different screen sizes.

# Technologies used
•⁠  ⁠HTML5 – for creating the structure of the website.
•⁠  ⁠⁠CSS3 – for styling, layouts, colours and responsiveness.

# Project structure
•⁠  ⁠index.HTML – homepage
•⁠  ⁠⁠product.HTML – product detail page
•⁠  ⁠⁠cart.html- shopping cart page
•⁠  ⁠⁠payment.HTML – checkout page
•⁠  ⁠⁠style.Css – common style sheet
•⁠  ⁠⁠images/ – folder containing sneaker images

# How to run the project
1.⁠ ⁠Open the project folder in VS code or any code editor.
2.⁠ ⁠⁠Open index.HTML in a web browser.
